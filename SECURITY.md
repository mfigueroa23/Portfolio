# Security Policy

## Supported versions
Only the live site at [marco.figueroa-sanchez.com](https://marco.figueroa-sanchez.com) and the latest `main` branch receive security fixes.

## Reporting a vulnerability
Please **do not** open a public issue for security problems. Instead, email [marco@figueroa-sanchez.com](mailto:marco@figueroa-sanchez.com) with:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact

## What to expect
- An acknowledgement within 72 hours.
- Updates as the report is triaged and fixed.
- Credit for the discovery once it's resolved, if you'd like it.

## Scope
**In scope:**
- The site frontend
- The `/api/contact` endpoint, for example injection in the contact email template or abuse of the endpoint

**Out of scope:**
- Third-party services the site depends on
- Denial-of-service or high-volume testing
